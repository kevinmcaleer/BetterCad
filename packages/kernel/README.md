# @bettercad/kernel

The modelling kernel: OpenCascade (opencascade.js, WASM) running in a Web Worker. Arrives with epic #4.

This package is a placeholder so the workspace has its final shape; nothing imports it yet.

## WASM

`wasm/` will hold `opencascade.full.wasm` (or a custom build) and its JS glue, unmodified from opencascade.js.
